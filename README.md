## 🧠 Automated Sinusitis Detection

> AI-powered CT scan analysis system

A deep-learning based application designed to analyse CT scans,
detect sinusitis and highlight affected regions.

**Stack:**  
`Python` `Deep Learning` `Image Processing` `FastAPI`

---

## 🔐 Hybrid Image & Audio Steganography

> Security meets multimedia

A steganography project combining hidden-data techniques with
cryptographic protection for image and audio files.

**Stack:**  
`Python` `Flask` `AES-256` `RSA-2048` `SHA-256` `PyWavelets`

---

## 🐳 Amazon Backend — Dockerized API

> Backend → Container → Deployment

A FastAPI backend developed with a focus on API development,
database integration and containerization.

**Stack:**  
`FastAPI` `Python` `SQLAlchemy` `Docker` `Docker Compose`
